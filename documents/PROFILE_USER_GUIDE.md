# Profile Pages - Quick User Guide

## 🎯 Overview
The profile pages have been completely redesigned with a modern UI and enhanced functionality. This guide covers all the new features and how to use them.

## 👤 Accessing Your Profile

1. **Navigate to Profile**: Click on your avatar or "Profile" in the navigation menu
2. **View Others' Profiles**: Click on any user's name or avatar throughout the app

## ✏️ Editing Your Profile

### Basic Information

1. Click the **"Edit Profile"** button in the header
2. Update any of these fields:
   - **Name**: Your full name
   - **Bio**: Brief description about yourself (supports multiple lines)
   - **Location**: Your city/country
   - **Phone**: Contact number
   - **Website**: Your personal or company website
   
3. **For Freelancers only**:
   - **Hourly Rate**: Your rate in USD
   - **Availability**: Choose from Available/Busy/Unavailable
   
4. **For Clients only**:
   - **Company Name**: Your organization
   - **Industry**: Your business sector
   - **Company Size**: Select from dropdown

5. Click **"Save Changes"** or **"Cancel"** to exit edit mode

### Uploading Profile Picture

1. Hover over your avatar
2. Click the **camera icon** at the bottom-right
3. Select an image from your device
4. Wait for the upload to complete (spinner will show)
5. Your new avatar will appear automatically

## 🎨 Managing Skills (Freelancers Only)

### Adding Skills

**Method 1: During Edit Mode**
1. Click **"Edit Profile"**
2. Scroll to the Skills section
3. Type a skill name in the input field
4. Press **Enter** or click the **"+"** button
5. Repeat for all your skills
6. Click **"Save Changes"** when done

**Method 2: Empty State**
If you have no skills:
1. Click **"Add Skills"** button in the empty state
2. Follow steps 2-6 above

### Removing Skills

1. Enter edit mode
2. Click the **"X"** next to any skill
3. Click **"Save Changes"** to confirm

### Tips
- Add 5-10 relevant skills for best results
- Use specific skill names (e.g., "React.js" not just "React")
- Skills help clients find you in searches

## 📂 Managing Portfolio (Freelancers Only)

### Adding a Project

1. Scroll to the Portfolio section
2. Click **"Add Project"** button
3. Fill in the modal form:
   - **Project Title** (required): Name of the project
   - **Description** (required): Detailed description
   - **Project URL** (optional): Live demo or GitHub link
   - **Image URL** (optional): Screenshot or preview image
4. Click **"Add Portfolio Item"**

### Editing a Project

1. Hover over a portfolio card
2. Click the **blue edit icon** (appears on hover)
3. Update any fields in the modal
4. Click **"Update Portfolio Item"**

### Deleting a Project

1. Hover over a portfolio card
2. Click the **red trash icon** (appears on hover)
3. Confirm deletion in the popup
4. Project will be removed immediately

### Tips
- Add 3-5 of your best projects
- Include clear descriptions with technologies used
- Add project URLs when possible to showcase live work
- Use high-quality images (recommended: 800x600px)

### Color Indicators

**Availability Badge** (Freelancers):
- 🟢 Green = Available for work
- 🟡 Yellow = Busy with current projects
- 🔴 Red = Not available

**Stats Cards**:
- Each card shows key metrics
- Hover to see subtle lift animation

**Portfolio Cards**:
- Hover for edit/delete buttons (own profile)
- Click "View Project" to open external links

- Single column layout
- Full-width buttons
- Optimized touch targets

**Tablet** (640px - 1024px):
- 2-column layout

**Desktop** (> 1024px):
- 4-column stats grid

## 🔍 View Mode vs Edit Mode

### View Mode (Default)
- Shows all your information
- Others can see this view
- Clean, professional display
- Action buttons available

### Edit Mode
- Input fields appear
- Add/remove capabilities active
- Changes are not saved until you click "Save"
- Cancel returns to previous state

## 🐛 Troubleshooting

### Avatar won't upload?
- Check file size (max 5MB)
- Supported formats: JPG, PNG, GIF
- Check internet connection

### Changes not saving?
- Ensure all required fields are filled
- Check for error messages
- Try refreshing the page

### Portfolio image not showing?
- Verify the image URL is accessible
- Must be a direct image link (ends in .jpg, .png, etc.)
- Try a different hosting service

### Skills not adding?
- Make sure you're in edit mode
- Press Enter or click the + button
- Don't forget to save changes

## 📱 Keyboard Shortcuts

- **Enter**: Add skill (when in skill input)
- **Escape**: Close modal (when modal is open)
- **Tab**: Navigate between form fields

## 🔒 Privacy & Security

- Only you can edit your profile
- Others can only view your public information
- Email is always private
- Phone number is only visible if you add it
- Portfolio URLs open in new tabs
